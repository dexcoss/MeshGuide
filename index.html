МЭШ Layout Editor + Theme Studio PRO

Визуальный редактор для «Московской электронной школы»: переставляйте блоки, меняйте текст и картинки, включайте стеклянный стиль, тёмную тему, анимации, музыку и свой шрифт. Работает на компьютере и телефоне.

1. Что понадобится

Скрипт работает как расширение-«надстройка»: браузер запускает его на странице school.mos.ru. Нужны два пункта:

БраузерChrome, Edge, Яндекс.Браузер, Opera, Firefox
Расширение Tampermonkeyбесплатное, ставится за одну минуту
Аккаунт МЭШобычный вход на school.mos.ru
Важно: скрипт ничего не отправляет на сторонние серверы. Все настройки хранятся в самом браузере.

2. Установите Tampermonkey

Выберите свой браузер и нажмите на ссылку — откроется официальный магазин расширений.

Chrome / Яндекс / EdgeChrome Web Store Firefoxaddons.mozilla.org Operaaddons.opera.com Телефон (Android)Kiwi / Firefox + Tampermonkey
Chrome, Яндекс и Edge (новые версии): если скрипт не запускается, откройте chrome://extensions (или edge://extensions), включите «Режим разработчика», затем в настройках Tampermonkey включите «Режим пользовательского скрипта» (или «User scripts»).

3. Добавьте скрипт в Tampermonkey

Два способа: вставить код вручную (рекомендуется) или скачать файл и импортировать его.

Способ А — вставить код (рекомендуется)

  1. Откройте панель Tampermonkey

    Нажмите на иконку Tampermonkey в правом верхнем углу браузера (значок «пазла», если он спрятан) и выберите «Панель управления» / Dashboard.

  2. Создайте новый скрипт

    Перейдите на вкладку с символом + (создать новый скрипт). Откроется редактор с шаблонным текстом.

  3. Скопируйте код этой страницы

    Нажмите кнопку «Копировать код» ниже или вверху страницы. Появится уведомление «Код скопирован».

  4. Вставьте код в редактор

    В редакторе Tampermonkey выделите весь шаблон: Ctrl+A (на Mac: ⌘+A), удалите его и вставьте код: Ctrl+V.

  5. Сохраните

    Нажмите Ctrl+S или кнопку File → Save. Скрипт появится в списке и будет включён (переключатель зелёный).

  6. Откройте МЭШ

    Перейдите на school.mos.ru и обновите страницу (F5). В правом верхнем углу появится кнопка «Редактор».

Способ Б — скачать файл и импортировать

  1. Скачайте файл

    Нажмите «Скачать .user.js» ниже. Сохранится файл mes-layout-editor.user.js.

  2. Импортируйте в Tampermonkey

    Откройте Панель управления → вкладка «Утилиты» (Utilities) → раздел Import → Выбрать файл и укажите скачанный файл. Подтвердите установку кнопкой Install.

5. Если что-то не работает

    
Самые частые вопросы.


    

      Кнопки «Редактор» нет на странице
      
Проверьте, что скрипт включён в Панели управления Tampermonkey (переключатель зелёный). Адрес должен начинаться с school.mos.ru. Обновите страницу клавишей F5. Если не помогло — проверьте, что Tampermonkey включён для этого сайта в значке расширения.

    

    

      В Chrome / Яндекс / Edge скрипт не запускается
      
Включите «Режим разработчика» на странице расширений и «Режим пользовательского скрипта» в настройках Tampermonkey. Затем перезапустите браузер.

    

    

      Ошибка при вставке кода или «Syntax error»
      
Скорее всего, в редакторе остался старый шаблон. Выделите весь текст Ctrl+A, удалите и вставьте код заново. Строка // ==UserScript== должна быть самой первой.

    

    

      Сайт стал тормозить
      
Выключите «Эффект стекла», снег / дождь и видеофон во вкладке «Оформление». Для слабых устройств включите «Снизить нагрузку» в эффектах.

    

    

      Настройки пропали после очистки браузера
      
Заранее сохраняйте резервную копию кнопкой «Экспорт» (файл JSON). После переустановки используйте «Импорт».

    

    

      Картинки или музыка не сохраняются
      
Проверьте, что браузер не блокирует хранилище сайта и не работает в режиме «Инкогнито» (там данные не сохраняются после закрытия окна). Большие файлы сжимаются автоматически.

    


    
Не меняйте текст скрипта вручную без необходимости: при ошибке в коде страница может перестать загружаться корректно. Для возврата к исходной версии используйте файл, скачанный на этой странице.

      if (!e) { e = { kind, key, assetKey: null, url: '' }; list.push(e); }
      const old = e.assetKey;
      if (file) {
        const blob = await shrinkImage(file, IMG_MAX);
        const ak = 'img_' + uid();
        await AssetStore.put(ak, blob);
        e.assetKey = ak; e.url = '';
      } else { e.assetKey = null; e.url = url; }
      commit();
      await this.applyAll();
      if (old && old !== e.assetKey) AssetStore.drop(old);
    },
    restoreImg(img) {
      if (!img.dataset.mesNew) return;
      const pic = img.parentElement;
      img.src = img.dataset.mesOrig;
      if (img.dataset.mesSrcset) img.setAttribute('srcset', img.dataset.mesSrcset);
      if (pic && pic.tagName === 'PICTURE') $$('source[data-mes-srcset]', pic).forEach(s => { s.setAttribute('srcset', s.dataset.mesSrcset); delete s.dataset.mesSrcset; });
      if (img.dataset.mesFit) img.style.removeProperty('object-fit');
      ['mesNew', 'mesOrig', 'mesSrcset', 'mesFit'].forEach(k => delete img.dataset[k]);
    },
    restore(el) {
      const kind = this.kindOf(el), key = this.keyOf(el);
      const list = getImages();
      const i = list.findIndex(e => e.kind === kind && e.key === key);
      if (i < 0) return;
      const [removed] = list.splice(i, 1);
      if (kind === 'img') Array.from(document.images).forEach(img => { if (img.dataset.mesOrig === key) this.restoreImg(img); });
      else { try { $$(key).forEach(n => { n.style.removeProperty('background-image'); delete n.dataset.mesBg; }); } catch (err) {} }
      AssetStore.drop(removed.assetKey);
      commit();
    }
  };
  /* =========================================================
   * 4c. ЗАМЕНА ТЕКСТА
   * ========================================================= */
  const TextEditor = {
    orig: new WeakMap(), applied: new WeakMap(),
    walk(fn) {
      const w = document.createTreeWalker(document.body, NodeFilter.SHOW_TEXT, {
        acceptNode: n => {
          const p = n.parentElement; if (!p) return 2;
          const t = p.tagName;
          if (t === 'SCRIPT' || t === 'STYLE' || t === 'NOSCRIPT' || t === 'TEXTAREA') return 2;
          if (p.closest('#mes-editor-root')) return 2;
          return 1;
        }
      });
      let n; while ((n = w.nextNode())) fn(n);
    },
    applyAll() {
      const list = getTexts();
      if (!list.length) return;
      const m = new Map(); list.forEach(t => m.set(t.from, t.to));
      this.walk(n => {
        if (this.applied.has(n) && n.nodeValue.trim() === this.applied.get(n)) return;
        const v = n.nodeValue, t = v.trim();
        if (!t || !m.has(t)) return;
        const to = m.get(t);
        this.orig.set(n, v); this.applied.set(n, to);
        n.nodeValue = v.replace(t, to);
      });
    },
    revertAll() {
      this.walk(n => {
        if (!this.orig.has(n)) return;
        if (n.nodeValue.trim() === this.applied.get(n)) n.nodeValue = this.orig.get(n);
        this.orig.delete(n); this.applied.delete(n);
      });
    },
    part(el) {
      if (!el) return null;
      for (const n of el.childNodes) {
        if (n.nodeType === 3 && n.nodeValue.trim()) {
          const cur = n.nodeValue.trim();
          const from = this.orig.has(n) ? this.orig.get(n).trim() : cur;
          return { node: n, from, cur };
        }
      }
      return null;
    },
    set(from, to) {
      const list = getTexts();
      const i = list.findIndex(t => t.from === from);
      to = (to || '').trim();
      if (!to || to === from) { if (i >= 0) list.splice(i, 1); }
      else if (i >= 0) list[i].to = to;
      else list.push({ from, to });
      commit();
      this.revertAll(); this.applyAll();
    }
  };

   * 4d. БЛОКИ

  const Blocks = {
    sig(n) { return n.tagName + '|' + normCls(n.getAttribute('class')); },
    findBlock(el) {
      let node = el;
      while (node && node !== document.body && node.parentElement) {
        const p = node.parentElement; const sig = this.sig(node);
        let same = 0;
        for (const c of p.children) if (this.sig(c) === sig) same++;
        if (same >= 2 && p !== document.body) return p;
        node = p;
      }
      return el.parentElement && el.parentElement !== document.body ? el.parentElement : el;
    },
    role(c, own, bg) {
      const t = c.tagName;
      if (t === 'IMG') return 'Картинка';
      if (bg && !own) return 'Фон';
      if (t === 'svg' || t === 'SVG') return 'Иконка';
      if (t === 'BUTTON' || c.getAttribute('role') === 'button') return 'Кнопка';
      if (t === 'A') return 'Ссылка';
      if (/^H[1-6]$/.test(t)) return 'Заголовок';
      if (own) {
        const s = own.cur;
        if (/^\d{1,2}[:.]\d{2}(\s*[–—-]\s*\d{1,2}[:.]\d{2})?$/.test(s)) return 'Время';
        if (/^[\d.,\s]+$/.test(s)) return 'Число';
        if (/каб|ауд/i.test(s)) return 'Кабинет';
        return 'Текст';
      }
      return 'Блок';
    },
    parts(root) {
      const out = [];
      const SKIP = /^(SCRIPT|STYLE|NOSCRIPT|BR|HR|PATH|LINK|META)$/i;
      const walk = (el, d) => {
        for (const c of el.children) {
          if (out.length >= 60) return;
          if (SKIP.test(c.tagName) || c.closest('#mes-editor-root')) continue;
          const r = c.getBoundingClientRect();
          if (!r.width && !r.height) continue;
          const own = TextEditor.part(c);
          const t = c.tagName;
          const isSvg = typeof SVGElement !== 'undefined' && c instanceof SVGElement;
          const bg = isSvg ? null : ImageReplacer.bgUrl(c);
          const kids = c.children.length;
          if (!(own || t === 'IMG' || t === 'BUTTON' || t === 'A' || bg || isSvg || kids)) continue;
          out.push({ el: c, depth: d, role: this.role(c, own, bg), text: (own ? own.cur : (kids ? kids + ' эл.' : '')).slice(0, 40) });
          if (!isSvg && d < 3) walk(c, d + 1);
        }
      };
      if (root) walk(root, 0);
      return out;
    }
  };
  /* =========================================================
   * 5. SURFACES — эвристика по фактическому цвету элементов.
   *    data-mes-s  = 1|2  светлая «поверхность» (2 = вложенная)
   *    data-mes-m  = серая поверхность / плашка
   *    data-mes-w  = огромная обёртка страницы
   *    data-mes-t  = 1|2  тёмный/серый текст (для тёмной темы)
   *    data-mes-bc = светлая рамка
   *    data-mes-pb = светлый ::before/::after (только при наведении)
   *    data-mes-a  = элемент анимируется прямо сейчас
   *
   *    v1.9.1:
   *    • rk — «как элемент выглядит после наших правок»: 'dark' (будет тёмным),
   *      'keep' (остаётся как есть: цветной/светлый без текста). Цвет текста
   *      выбирается по rk ближайшего предка, а не по исходному цвету фона.
   *    • Мелкие светлые плашки С ТЕКСТОМ (ромбики с цифрами, «Год», «Школа»,
   *      бейджи) тоже темнеют — текст внутри больше не «белое на белом».
   *    • Тонкие светлые полоски (рейтинг-бары) прозрачны для выбора цвета текста.
   *    • Градиент без насыщенных цветов (линии сетки графика) не считается
   *      цветным фоном — текст поверх него светлеет.
   *    • Элементы, у которых поменялся класс / появился текст, ПЕРЕПРОВЕРЯЮТСЯ
   *      (раньше они считались «уже виденными» и оставались белыми).
   * ========================================================= */
  const Surfaces = {
    seen: new WeakSet(),
    kind: new WeakMap(),
    surf: new WeakSet(),
    rk: new WeakMap(),
    hk: null,
    quiet: false,
    token: 0,
    animIdx: 0,
    ATTRS: ['data-mes-s', 'data-mes-m', 'data-mes-w', 'data-mes-t', 'data-mes-bc', 'data-mes-a', 'data-mes-pb'],
    rec: new Map(), hraf: 0, hpending: null, htimer: 0,
    needSurf() { const m = getTheme().misc; return !!(m.dark || m.glass); },
    parse(c) {
      if (!c) return null;
      const m = c.match(/rgba?\(([^)]+)\)/);
      if (!m) return null;
      const p = m[1].split(/[\s,\/]+/).filter(Boolean).map(parseFloat);
      if (p.length < 3 || p.some(isNaN)) return null;
      return { r: p[0], g: p[1], b: p[2], a: p.length > 3 ? p[3] : 1 };
    },
    lum(c) { return (0.299 * c.r + 0.587 * c.g + 0.114 * c.b) / 255; },
    sat(c) { return Math.max(c.r, c.g, c.b) - Math.min(c.r, c.g, c.b); },
    applyOps(ops) {
      for (const [el, k, v] of ops) {
        if (k.charCodeAt(0) === 45) el.style.setProperty(k, String(v));
        else el.setAttribute(k, v);
      }
    },
    reset() {
      this.token++;
      this.seen = new WeakSet(); this.kind = new WeakMap(); this.surf = new WeakSet(); this.rk = new WeakMap();
      this.rec.clear();
      $$(this.ATTRS.map(a => `[${a}]`).join(',')).forEach(el => this.ATTRS.forEach(a => el.removeAttribute(a)));
    },
    // забыть всё про элемент, чтобы visit() заново его оценил (анимацию не трогаем)
    forget(el) {
      this.seen.delete(el); this.kind.delete(el); this.surf.delete(el); this.rk.delete(el);
      for (const a of this.ATTRS) if (a !== 'data-mes-a') el.removeAttribute(a);
    },
    scan() {
      if (!this.needSurf()) return;
      const list = document.body.getElementsByTagName('*');
      const tok = ++this.token;
      this.animIdx = 0;
      const chunk = LITE ? 150 : 400;
      let i = 0;
      const step = () => {
        if (tok !== this.token) return;
        const ops = [];
        const end = Math.min(i + chunk, list.length);
        for (; i < end; i++) { try { this.visit(list[i], ops); } catch (e) {} }
        this.applyOps(ops);
        if (i < list.length) setTimeout(step, LITE ? 16 : 0);
      };
      step();
    },
    // nodes — новые/изменённые узлы; force — Set узлов, которые нужно перепроверить с нуля
    fast(nodes, force) {
      if (!this.needSurf() || !nodes.length) return;
      let list = Array.from(new Set(nodes));
      if (list.length <= 500) list.sort((a, b) => (a.compareDocumentPosition(b) & 4 ? -1 : 1));
      const ops = [];
      let budget = LITE ? 2500 : 5000;
      outer: for (const root of list) {
        if (!root.isConnected) continue;
        if (budget-- <= 0) break;
        const f = !!(force && force.has(root));
        this.quiet = f;
        if (f) this.forget(root);
        try { this.visit(root, ops); } catch (e) {}
        const all = root.querySelectorAll('*');
        for (let i = 0; i < all.length; i++) {
          if (budget-- <= 0) break outer;
          if (f && i < 80) this.forget(all[i]);
          try { this.visit(all[i], ops); } catch (e) {}
        }
      }
      this.quiet = false;
      this.applyOps(ops);
    },
    // может ли элемент стать «плашкой» (маленький, не тёмный) — нужен для перепроверки при появлении текста
    maybeChip(el) {
      if (!this.seen.has(el) || this.rk.get(el) === 'dark') return false;
      const r = el.getBoundingClientRect();
      return r.width > 0 && r.width < 400 && r.height < 120;
    },
    // как будет выглядеть фон под элементом (включая сам элемент): 'dark' | 'keep' | null (фон страницы)
    renderOf(el) {
      for (let p = el; p && p !== document.body; p = p.parentElement) {
        const r = (this.hk && this.hk.get(p)) || this.rk.get(p);
        if (r) return r;
      }
      return null;
    },
    hasSurfAncestor(el) {
      for (let p = el.parentElement; p && p !== document.body; p = p.parentElement) if (this.surf.has(p)) return true;
      return false;
    },
    // цвет градиента/картинки: 'c' — реально цветной фон, null — прозрачный/серый (линии сетки и т.п.)
    imageKind(bi) {
      if (bi.indexOf('url(') >= 0) return 'c';
      const cols = bi.match(/rgba?\([^)]+\)/g) || [];
      for (const s of cols) {
        const c = this.parse(s);
        if (c && c.a > 0.3 && this.sat(c) > 60) return 'c';
      }
      return null;
    },
    // hover=true — «пробный» визит без запоминания (для наведения/фокуса)
    visit(el, ops, hover) {
      if (!hover && this.seen.has(el)) return;
      if (typeof SVGElement !== 'undefined' && el instanceof SVGElement) { if (!hover) this.seen.add(el); return; }
      const tag = el.tagName;
      if (tag === 'SCRIPT' || tag === 'STYLE' || tag === 'IMG' || tag === 'VIDEO' || tag === 'CANVAS' || tag === 'NOSCRIPT' || tag === 'IFRAME') { if (!hover) this.seen.add(el); return; }
      if (el.id === 'mes-editor-root' || el.closest('#mes-editor-root') || el.id === 'mes-theme-effects' || el.id === 'mes-bg-video' || el.id === 'mes-bg-layer') { if (!hover) this.seen.add(el); return; }
      const rect = el.getBoundingClientRect();
      if (!rect.width && !rect.height) return;
      const cs = getComputedStyle(el);
      if (cs.display === 'none' || cs.display === 'contents') return;
      if (!hover) this.seen.add(el);
      const bg = this.parse(cs.backgroundColor);
      let k = null;
      if (bg && bg.a > 0.3) {
        const lum = this.lum(bg);
        k = this.sat(bg) > 60 ? 'c' : lum > 0.78 ? 'l' : lum > 0.45 ? 'm' : 'd';
      } else if (cs.backgroundImage && cs.backgroundImage !== 'none') {
        k = this.imageKind(cs.backgroundImage);
      }
      if (k && !hover) this.kind.set(el, k);
      // rt — как элемент выглядит ПОСЛЕ наших правок
      let rt = null;
      if (k === 'c' || k === 'd') rt = 'keep';
      if (k === 'l' || k === 'm') {
        const W = window.innerWidth, H = window.innerHeight;
        if (rect.width >= W * 0.95 && rect.height >= H * 0.8) {
          ops.push([el, 'data-mes-w', '1']);
          rt = 'dark';
        } else if (rect.width >= 60 && rect.height >= 28) {
          const nested = this.hasSurfAncestor(el);
          if (!hover) this.surf.add(el);
          ops.push([el, 'data-mes-s', nested ? '2' : '1']);
          if (k === 'm') ops.push([el, 'data-mes-m', '1']);
          rt = 'dark';
          if (!hover && !this.quiet && !nested && rect.width > 200 && rect.height > 40 && rect.height < 600 && cs.position !== 'fixed' && cs.position !== 'sticky') {
            ops.push([el, 'data-mes-a', '1']);
            ops.push([el, '--mes-i', Math.min(this.animIdx++, 8)]);
          }
        } else if (rect.width >= 20 && rect.height >= 20) {
          // мелкая светлая плашка: ромбик с цифрой, «Год», «Школа», бейдж…
          const tx = el.textContent;
          if (tx && tx.length < 80 && tx.trim()) {
            ops.push([el, 'data-mes-s', '2']);
            ops.push([el, 'data-mes-m', '1']);
            rt = 'dark';
          } else rt = 'keep'; // светлая иконка/кнопка без текста — остаётся белой, иконка тёмная
        }
        // тонкие полоски (< 20px) — прозрачны для выбора цвета текста (rt = null)
      }
      if (rt) (hover ? this.hk : this.rk).set(el, rt);
      if (parseFloat(cs.borderTopWidth) > 0 && cs.borderTopStyle !== 'none') {
        const bc = this.parse(cs.borderTopColor);
        if (bc && bc.a > 0.2 && this.lum(bc) > 0.8 && this.sat(bc) < 40) ops.push([el, 'data-mes-bc', '1']);
      }
      if (hover) {
        for (const ps of ['::before', '::after']) {
          const pc = getComputedStyle(el, ps);
          if (!pc || pc.content === 'none' || pc.content === 'normal' || pc.display === 'none') continue;
          const pb = this.parse(pc.backgroundColor);
          if (pb && pb.a > 0.3 && this.lum(pb) > 0.78 && this.sat(pb) < 60) { ops.push([el, 'data-mes-pb', '1']); break; }
        }
      }
      let hasText = tag === 'INPUT' || tag === 'TEXTAREA' || tag === 'SELECT';
      if (!hasText) {
        for (const n of el.childNodes) { if (n.nodeType === 3 && n.nodeValue.trim()) { hasText = true; break; } }
      }
      if (hasText) {
        const tc = this.parse(cs.color);
        if (tc && tc.a > 0.3 && this.sat(tc) < 50) {
          // светлеем текст только если реально под ним будет тёмный фон (или фон страницы)
          const bk = this.renderOf(el);
          if (bk !== 'keep') {
            const l = this.lum(tc);
            if (l < 0.3) ops.push([el, 'data-mes-t', '1']);
            else if (l < 0.55) ops.push([el, 'data-mes-t', '2']);
          }
        }
      }
    },
    /* ---------- hover / focus / active ---------- */
    hoverSchedule(target) {
      this.hpending = target;
      if (this.hraf) return;
      this.hraf = requestAnimationFrame(() => { this.hraf = 0; try { this.hoverRun(this.hpending); } catch (e) {} });
    },
    hoverRun(t) {
      const keep = new Map();
      const keepAdd = (el, k) => { let s = keep.get(el); if (!s) keep.set(el, (s = new Set())); s.add(k); };
      if (this.needSurf() && t && t.nodeType === 1 && !t.closest('#mes-editor-root')) {
        // порядок: от внешнего предка к целевому элементу, затем его потомки —
        // чтобы цвет текста считался по уже определённому фону родителей
        const chain = [];
        let p = t;
        for (let i = 0; i < 6 && p && p !== document.body && p !== document.documentElement; i++, p = p.parentElement) chain.push(p);
        chain.reverse();
        const list = chain.slice();
        const kids = t.querySelectorAll('*');
        const lim = Math.min(kids.length, LITE ? 25 : 60);
        for (let i = 0; i < lim; i++) list.push(kids[i]);
        for (const el of list) { const m = this.rec.get(el); if (m) m.forEach((_, k) => keepAdd(el, k)); }
        const ops = [];
        this.hk = new WeakMap();
        for (const el of list) { try { this.visit(el, ops, true); } catch (e) {} }
        this.hk = null;
        for (const [el, k, v] of ops) {
          if (k.charCodeAt(0) === 45) continue;
          let m = this.rec.get(el);
          const mine = m && m.has(k);
          if (el.hasAttribute(k) && !mine) continue;
          if (!mine) { if (!m) this.rec.set(el, (m = new Map())); m.set(k, true); el.setAttribute(k, v); }
          keepAdd(el, k);
        }
      }
      clearTimeout(this.htimer);
      this.htimer = setTimeout(() => this.hoverClean(keep), 350);
    },
    hoverClean(keep) {
      for (const [el, m] of this.rec) {
        for (const k of Array.from(m.keys())) {
          if (keep.get(el) && keep.get(el).has(k)) continue;
          el.removeAttribute(k); m.delete(k);
        }
        if (!m.size) this.rec.delete(el);
      }
    }
  };
  /* =========================================================
   * 5b. АНИМАЦИЯ ПОЯВЛЕНИЯ новых блоков
   * ========================================================= */
  const Anim = {
    lastParent: new WeakMap(),
    check(el) {
      if (!el || el.nodeType !== 1) return 0;
      const tag = el.tagName;
      if (/^(SCRIPT|STYLE|NOSCRIPT|IMG|CANVAS|VIDEO|IFRAME|SVG|LINK|META)$/i.test(tag)) return 0;
      if (el.id === 'mes-editor-root' || el.id === 'mes-theme-effects' || el.id === 'mes-bg-video' || el.id === 'mes-bg-layer') return 0;
      if (el.closest('#mes-editor-root')) return 0;
      const cs = getComputedStyle(el);
      if (cs.display === 'none') return 0;
      if (cs.display === 'contents') return 2;
      if (cs.position === 'absolute' || cs.position === 'fixed' || cs.position === 'sticky') return 0;
      if (cs.transform !== 'none') return 0;
      const r = el.getBoundingClientRect();
      if (r.width < 140 || r.height < 32 || r.height > 900) return 0;
      if (r.bottom < -50 || r.top > window.innerHeight + 250) return 0;
      return 1;
    },
    animate(nodes) {
      const m = getTheme().misc;
      if (!m.anim || m.anim === 'none' || !nodes.length) return;
      const cap = LITE ? 12 : 24;
      const targets = [];
      const stamp = performance.now();
      const collect = (el, d) => {
        if (targets.length >= cap) return;
        const q = this.check(el);
        if (q === 0) return;
        if (q === 2) { if (d < 3) for (const c of el.children) collect(c, d + 1); return; }
        if (el.parentElement && el.parentElement.closest('[data-mes-a]')) return;
        const kids = d === 0 ? Array.from(el.children).filter(c => this.check(c) === 1) : [];
        if (kids.length >= 2) kids.forEach(c => { if (targets.length < cap) targets.push(c); });
        else targets.push(el);
      };
      const roots = nodes.length > 40 ? nodes.slice(0, 40) : nodes;
      for (const root of roots) {
        if (!root.isConnected) continue;
        const par = root.parentElement;
        const prev = par && this.lastParent.get(par);
        if (prev && prev !== stamp && stamp - prev < 350) continue;
        collect(root, 0);
        if (par) this.lastParent.set(par, stamp);
      }
      let idx = 0;
      for (const el of targets) {
        el.style.setProperty('--mes-i', String(Math.min(idx++, 8)));
        el.setAttribute('data-mes-a', '1');
      }
    }
  };
  document.addEventListener('animationend', (e) => {
    const el = e.target;

  }, true);

  const ThemeEngine = {
    _face: null, _fontKey: null,
    async apply() {
      const t = getTheme();
      this.applyAutoDark(t.misc);
      await this.applyBackground(t.background, t.misc);

  const EffectsEngine = {
    canvas: null, ctx: null, particles: [], raf: null, mode: null, cfg: null, key: '', last: 0,
    apply(cfg) {

      if (key === this.key && (this.canvas || !(cfg.snow || cfg.rain || cfg.stars))) return;
      this.key = key; this.cfg = cfg;

      if (!modes.length) return this.stop();

    start() {

        this.canvas = document.createElement('canvas'); this.canvas.id = 'mes-theme-effects';
        this.canvas.style.cssText = 'position:fixed;inset:0;pointer-events:none;z-index:0;';

    spawn() {
      const base = this.cfg?.lowPower ? 40 : LITE ? 70 : 120;
      const count = Math.floor((this.cfg?.intensity || 1) * base);
      this.particles = []; for (let i = 0; i < count; i++) this.particles.push(this.makeParticle());
    },
    makeParticle() {
      const w = this.canvas.width, h = this.canvas.height;
      if (this.mode === 'rain') return { x: Math.random() * w, y: Math.random() * h, vx: 0, vy: 8 + Math.random() * 6, len: 8 + Math.random() * 10 };
      if (this.mode === 'stars') return { x: Math.random() * w, y: Math.random() * h, r: Math.random() * 1.5 + 0.3, tw: Math.random() * 0.02 };
      return { x: Math.random() * w, y: Math.random() * h, r: Math.random() * 2 + 1, vx: -1 + Math.random() * 2, vy: 0.5 + Math.random() * 1.5 };
    },
    resume() { if (this.canvas && !this.raf && !document.hidden) this.loop(); },
    loop() {
      if (document.hidden || !this.canvas) { this.raf = null; return; }
      this.raf = requestAnimationFrame(() => this.loop());
      const now = performance.now();
      if (LITE) { if (now - this.last < 33) return; this.last = now; }
      const c = this.ctx, w = this.canvas.width, h = this.canvas.height; c.clearRect(0, 0, w, h);
      const p = this.particles;
      if (this.mode === 'rain') {
        c.strokeStyle = 'rgba(180,200,255,0.7)'; c.lineWidth = 1;
        c.beginPath();
        p.forEach(pt => { c.moveTo(pt.x, pt.y); c.lineTo(pt.x + pt.vx, pt.y + pt.len); pt.y += pt.vy; if (pt.y > h) { pt.y = -10; pt.x = Math.random() * w; } });

        c.fillStyle = 'rgba(255,255,200,0.9)';
        const d = Date.now();
        p.forEach(pt => { c.globalAlpha = 0.5 + 0.5 * Math.sin(d * pt.tw); c.beginPath(); c.arc(pt.x, pt.y, pt.r, 0, Math.PI * 2); c.fill(); });
        c.globalAlpha = 1;
      } else {
        c.fillStyle = 'rgba(255,255,255,0.9)';
        c.beginPath();
        p.forEach(pt => { c.moveTo(pt.x + pt.r, pt.y); c.arc(pt.x, pt.y, pt.r, 0, Math.PI * 2); pt.x += pt.vx + Math.sin(pt.y * 0.01) * 0.3; pt.y += pt.vy; if (pt.y > h) { pt.y = -10; pt.x = Math.random() * w; } if (pt.x < -10) pt.x = w + 10; if (pt.x > w + 10) pt.x = -10; });
        c.fill();
      }
    },
    stop() { if (this.raf) cancelAnimationFrame(this.raf); this.raf = null; if (this.canvas) { this.canvas.remove(); this.canvas = null; this.ctx = null; this.particles = []; } }

  const DragDrop = {
    dragging: null, placeholder: null,
    init() {
      this.placeholder = document.createElement('div'); this.placeholder.style.cssText = 'height:2px;background:#fff;box-shadow:0 0 0 1px #000;margin:2px 0;';

      document.addEventListener('keydown', this.onKey.bind(this));

    onDown(e) {
      if (!App.editing || e.target.closest('#mes-editor-root')) return;
      const img = ImageReplacer.findImg(e.clientX, e.clientY);
      let el = img || e.target.closest('*');
      if (!el || !SelectorRegistry.isEditable(el)) return;
      if (e.altKey) el = Blocks.findBlock(el);
      this.dragging = { el, startX: e.clientX, startY: e.clientY, moved: false };
      App.select(el);
    },
    onMove(e) {
      if (!this.dragging) return;
      if (Math.abs(e.clientX - this.dragging.startX) + Math.abs(e.clientY - this.dragging.startY) < 5) return;
      this.dragging.moved = true; this.dragging.el.style.opacity = '0.5';
      const under = document.elementFromPoint(e.clientX, e.clientY);
      if (under && under.parentElement && under !== this.dragging.el && !this.dragging.el.contains(under)) {
        if (this.placeholder.parentElement) this.placeholder.remove();
        under.parentElement.insertBefore(this.placeholder, under);
      }
    },
    onUp() {
      if (!this.dragging) return;
      const d = this.dragging; this.dragging = null; d.el.style.opacity = '';
      if (this.placeholder.parentElement) {
        this.placeholder.parentElement.replaceChild(d.el, this.placeholder);
        const parent = d.el.parentElement;
        if (parent) {
          const idx = Array.from(parent.children).indexOf(d.el);
          StyleApplier.setRule(SelectorRegistry.selectorFor(d.el), { order: idx });
        }
      }
    },
    moveEl(el, delta, edge) {
      const parent = el && el.parentElement; if (!parent) return;
      const sibs = Array.from(parent.children).filter(c => c.nodeType === 1);
      const i = sibs.indexOf(el);
      const j = edge ? (delta < 0 ? 0 : sibs.length - 1) : i + delta;
      if (j < 0 || j >= sibs.length || j === i) return;
      parent.insertBefore(el, j > i ? sibs[j].nextSibling : sibs[j]);
      StyleApplier.setRule(SelectorRegistry.selectorFor(el), { order: j });
    },
    onKey(e) {
      if (!App.editing) return;
      if (e.key === 'Escape') { App.toggleEditing(false); return; }
      if (!App.selected || (e.target.closest && e.target.closest('#mes-editor-root'))) return;
      if (['ArrowUp', 'ArrowDown'].includes(e.key)) {
        this.moveEl(App.selected, e.key === 'ArrowUp' ? -1 : 1, e.ctrlKey);
        e.preventDefault();
      }
    }

  function boot() {
    log('Запуск v1.9.1' + (LITE ? ' (режим экономии)' : ''));
    EditorUI.mount();
    DragDrop.init();
    ThemeEngine.apply().catch(e => log('theme error', e));
    let tries = 0;
    const maxTries = LITE ? 6 : 12, every = LITE ? 1000 : 500;
    const light = () => {
      tries++;
      try { applyContent(); Surfaces.scan(); } catch (e) { log('apply error', e); }
      if (tries < maxTries) setTimeout(light, every);
    };
    setTimeout(light, 500);
    const onMutate = debounce(() => { try { applyContent(); Surfaces.scan(); } catch (e) {} }, LITE ? 900 : 350);
    const onImg = debounce(() => { try { ImageReplacer.applyAll().catch(() => {}); } catch (e) {} }, 150);
    const onRoute = debounce(() => { try { applyContent(); ThemeEngine.apply(); } catch (e) {} }, 300);
    const wrap = (name) => { const orig = history[name]; history[name] = function (...a) { const r = orig.apply(this, a); onRoute(); return r; }; };
    wrap('pushState'); wrap('replaceState');
    window.addEventListener('popstate', onRoute);
    const hv = (e) => { if (Surfaces.needSurf()) Surfaces.hoverSchedule(e.target); };
    const hopt = { capture: true, passive: true };
    document.addEventListener('pointerover', hv, hopt);
    document.addEventListener('pointerdown', hv, hopt);
    document.addEventListener('focusin', hv, hopt);
    document.addEventListener('pointerout', (e) => { if (!e.relatedTarget && Surfaces.needSurf()) Surfaces.hoverSchedule(null); }, hopt);
    const inEditor = (n) => { const el = n && (n.nodeType === 1 ? n : n.parentElement); return !!(el && el.closest && el.closest('#mes-editor-root')); };
    // Колбэк MutationObserver выполняется ДО отрисовки кадра:
    // новые карточки получают стекло/тёмный фон/анимацию мгновенно → никакого белого мерцания.
    // Элементы с изменившимся классом / появившимся текстом перепроверяются (force).
    new MutationObserver((muts) => {
      const surf = Surfaces.needSurf();
      const nodes = [], added = [];
      const force = new Set();
      let external = false, imgSrc = false;
      for (const m of muts) {
        if (m.type === 'childList') {
          if (inEditor(m.target)) continue;
          external = true;
          let textAdded = false;
          m.addedNodes.forEach(n => {
            if (n.nodeType === 1) { added.push(n); if (surf) nodes.push(n); }
            else if (n.nodeType === 3 && surf && n.nodeValue.trim()) textAdded = true;
          });
          // в уже известный элемент добавили текст (React) — он мог стать «плашкой»
          if (textAdded && m.target.nodeType === 1 && force.size < 60 && Surfaces.maybeChip(m.target)) { force.add(m.target); nodes.push(m.target); }
        } else if (m.type === 'attributes') {
          const el = m.target;
          if (!el || el.nodeType !== 1 || inEditor(el)) continue;
          if (m.attributeName === 'src') { if (el.tagName === 'IMG') imgSrc = true; continue; }
          if (!surf) continue;
          if (normCls(m.oldValue) === normCls(el.getAttribute('class'))) continue;
          if (force.size < 80) { force.add(el); nodes.push(el); }
        }
      }
      if (nodes.length) { try { Surfaces.fast(nodes, force); } catch (e) { Surfaces.quiet = false; } }
      if (added.length) { try { Anim.animate(added); } catch (e) {} }
      if (external) onMutate();
      if (imgSrc) onImg();
    }).observe(document.body, { childList: true, subtree: true, attributes: true, attributeFilter: ['class', 'src'], attributeOldValue: true });
  }

  else boot();
